# 游戏加载时 AOT 实验

## 目标

正式版已经把固定 E.BIN 的热点基本块编译成 S1C33 原生超块，但完整的
《伏魔记》8000 帧剧情轨迹中仍有约 8.92% 的客机指令来自 `.gam` Flash。
游戏内容和版本不固定，不能像 E.BIN 一样在构建仓库时按固定地址生成代码；
9288 的可用内存也不适合保存完整 JIT 代码缓存。

`--game-load-aot` 实现的是“加载时模板 AOT”：游戏载入后扫描七类常见的
6502 基本块形状，将块地址和操作数保存到固定表中；执行到对应地址时，直接进入
KF2 内已经由 C 编译器生成的 S1C33 模板。它不会在运行时生成机器码，因此不需要
可执行堆、指令缓存刷新 API 或额外的 JIT 内存。

## 安全边界

- 查找键使用当前 4 KiB bank 映射后的 24 位物理 PC，bank 改变时同步更新
  快速掩码。
- 模板不会跨越 4 KiB bank 边界；下一虚拟 bank 不一定映射到相邻物理页。
- 扫描到的操作数字节复制到固定记录中，最多保存 192 个块；记录和 512 项哈希表
  位于静态 scratch，不申请堆内存。
- 未匹配的入口直接走原 computed-goto 解释器。
- 客机执行 Flash 编程或擦除，只要范围与当前游戏重叠，就立即关闭全部游戏 AOT；
  后续继续由解释器执行，避免运行已经失效的代码快照。
- 游戏文件只在本机加载，不进入源码、测试报告或发布包。

这不是通用 6502 AOT 编译器。七个模板来自多游戏动态轨迹中重复且收益较高的
基本块形状；间接控制流、任意长度代码和未识别指令仍由解释器执行。

## 当前结果

使用同一份核心分别启用和关闭游戏加载时 AOT，比较最终画面校验和以及包含 CPU、
RAM、Flash、bank、Timer 和 LCD 的全状态哈希：

| 游戏 | 轨迹 | 匹配块 | AOT 执行指令 | 最终状态 |
|---|---:|---:|---:|---|
| 伏魔记 | 8000 帧剧情按键轨迹 | 136 | 5,601,877 | 一致 |
| 魔塔（可存档版） | 5000 帧无输入 | 43 | 0 | 一致 |
| 三国霸业 6980 | 5000 帧无输入 | 107 | 82 | 一致 |
| rpg-11 | 5000 帧无输入 | 136 | 5,547,822 | 一致 |

《伏魔记》命中的 5,601,877 条指令约占该 8000 帧轨迹全部 128,049,964 条
客机指令的 4.37%。在 `bbk9288-emulator` 的 S1C33 指令执行环境中，对同样的
5000 帧核心任务做两组独立冷启动配对计时，提升分别为 1.06 倍和 1.09 倍，
中心值约 1.08 倍。完整 GUI 流程仍受 20 Hz `MSG_TIMER` 节拍限制，不能用墙钟
时间衡量核心吞吐；以上结果也不能替代 9288 真机计时。

当前带设置和性能记录功能的实验 KF2 为 303,593 字节，相对 274,841 字节的
正式构建增加 28,752 字节。游戏 AOT 的固定记录和哈希表增加 9,472 字节
scratch；性能调试另使用 6,144 字节固定 PC 采样表，不申请堆内存。
`s6502_exec` 栈帧仍为 15 个字。是否在下一正式版默认启用，要以真机速度、
启动耗时和长时间稳定性测试为准。

## 运行时设置和性能日志

实验构建的游戏选择列表固定把 `[设置]` 放在第一项。方向键选择项目，Enter
或左右键切换：

- “加载时 AOT”控制下一次 `.gam` 加载是否扫描和启用模板，默认开启。
- “性能调试”控制指标采样和日志写入，默认关闭；日常运行无需承担采样开销。
- 设置以 8 字节带版本和校验的记录保存在 `A:\gam4980\GAM4980.CFG`。

性能调试开启时，正常退出一次游戏会向 `A:\gam4980\PERF.LOG` 追加一节纯文本。
日志包含：

- 核心初始化、游戏读取、AOT 扫描、首帧和会话耗时；时间值采用 9288 GUI
  Tick 原始单位，短于固件 Tick 精度的阶段可能显示为 0。
- Timer 批次、客机帧、实际画面变化、屏幕提交、ROM 读取次数和字节数。
- AOT 开关、扫描得到的块数、退出时是否仍有效、客机总周期和退出 PC。
- 最多 256 个按“虚拟 PC + 物理 PC”归并的热点样本，以及采样表溢出数。

热点采样在每个固定周期的核心执行片段结束后进行，不是逐条 6502 指令插桩；
因此它适合在真机上低成本定位长期热点，但 `hits` 不能解释为精确指令执行次数。
日志只在正常返回应用并退出本次游戏后落盘，掉电或死机前尚未提交的会话不会留下
完整记录。

模拟器端已验证设置的开/关与持久化、进入《伏魔记》主菜单和日志落盘。一次
55 秒会话记录到 3330 个客机帧、121 次画面变化、123 次屏幕提交、128 个游戏
AOT 块和 256 个热点 PC；关闭性能调试时核心采样计数保持为零。

## 构建

```bash
python3 build_9288.py \
  --sdk /path/to/app_env_9288 \
  --toolchain /path/to/piece-toolchain-llvm/build/bin \
  --game-load-aot
```

该选项依赖正式 E.BIN AOT 分派器，因此不能与 `--no-aot` 同时使用。
